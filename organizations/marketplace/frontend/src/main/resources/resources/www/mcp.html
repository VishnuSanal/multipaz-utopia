Marketplace MCP

Shop with an assistant.

An MCP-compatible assistant can browse the Utopia Marketplace, build a cart, and create a checkout link. You remain in control: you approve the credential and payment flow yourself.

Connect your MCP client

Use this endpoint with an MCP-compatible client when connected through the Utopia gateway:

/mcp

When running the MCP server directly, use http://localhost:3005/mcp.

How it works

Your assistant shops. You approve.

  1. Browse and prepare. Your assistant uses MCP tools to browse the catalog and build a cart.
  2. Receive a checkout link. The assistant sends the order to your browser or phone; it cannot complete the purchase itself.
  3. Present only what is needed. Age-restricted items request proof that you are over 18. Every order requests a payment credential.
  4. Approve the payment. The Marketplace verifies the credentials and UPay settles the transaction after you approve it when the Multipaz backend is configured.

Why it is safe to hand off

The assistant never gets the final say.

The checkout gate derives the amount from the Marketplace catalog, checks it against what your wallet signed, and re-checks the age policy over the disclosed claims. Verification happens before settlement, so an order the policy refuses is never charged.
